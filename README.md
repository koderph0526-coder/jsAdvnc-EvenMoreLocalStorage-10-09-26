NS:

-> .setItem => lagrer en verdi/string/array i en variabler vi setter den til å lagre det i, i dette tilfelle i local storage. In short: setItem kan også skrives som 'const localStorag = ("bla", "bla")', men koden blir kortere og mer effektiv når vi skriver 'localStorage.setItem("bla", "bla")'.

--> Local storage i dette tilfelle er bare et object som lagrer informasjonen vår.
